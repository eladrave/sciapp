System overview

Personal memory

Automatic and always on for every signed-in user. Private memory stays separate from shared resources.

Shared resources

Drafts stay private to administrators. Published excerpts can be retrieved by users. Review labels record an administrator’s review, not clinical certification.

New resource draft

PDF, PowerPoint, Word and text files. VTT/SRT can supply a video transcript. Older DOC/PPT files can be stored with a manual summary. MP3, WAV, M4A, MP4, WebM, OGG and FLAC uploads generate a speech transcript in the background.

Paste the video URL and provide a reviewed summary or transcript. For a page link, supply a summary/transcript or upload the audio/video to generate one. An uploaded media file can be the resource itself, without an external URL. Visual demonstrations are not interpreted.

For an uploaded document this box is filled in automatically from the file, including whole books; you do not need to type anything. Use material you have permission to share. Files remain private until a resource using them is published. Review extracted text against the original. Video URLs are citations; the app does not fetch a video from its page URL. Uploaded audio/video can generate an AI speech transcript for review.

AI models

Models apply to everyone. Changes take effect on the next request. Provider keys entered here are encrypted on the server and never returned to this page. The existing OpenAI Worker secret remains supported.

Leave blank to retain the key for this URL. A different URL requires its own key. Only public HTTPS endpoints are supported. Saving activates the provider for all users and sends relevant care context to it.

Higher reasoning can increase cost and latency. The selected provider and model must support tools for conversation and image input for photos. Use Provider default to omit reasoning parameters on providers that do not support them. Legacy mode uses the original fixed Cloudflare models.
